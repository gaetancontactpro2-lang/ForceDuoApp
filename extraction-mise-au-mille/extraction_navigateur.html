Extraction « Mise au mille » sans installation

Cette méthode n'installe rien et ne pilote pas Edge de l'extérieur. Un script travaille directement dans la page de l'appli, dans ton Edge habituel : il change la date jour après jour, déclenche l'extraction Excel, et te remet à la fin un seul fichier ZIP contenant tous les Excel renommés avec la date du programme (Mise_au_mille_2025-07-01.xlsx, etc.).

Étape 1 : lancer le script dans la page de l'appli

Méthode A : avec un favori (la plus simple)

  1. Affiche la barre de favoris d'Edge : Ctrl + Maj + B.
  2. Fais glisser ce bouton rouge dans la barre de favoris : Extraction Mise au mille
  3. Ouvre l'appli sur la page « Mise au mille », dans le même Edge.
  4. Clique sur le favori « Extraction Mise au mille ». Un panneau sombre apparaît en bas de la page.

Méthode B : avec la console (si le favori ne fait rien)

  1. Clique ici :
  2. Va sur l'onglet de l'appli, page « Mise au mille », appuie sur F12 puis clique sur l'onglet Console.
  3. Colle avec Ctrl + V puis appuie sur Entrée.
    Si Edge refuse de coller et demande de taper autoriser le collage (ou allow pasting), tape ces mots, appuie sur Entrée, puis colle à nouveau.
  4. Ferme la console avec F12. Le panneau sombre est en bas de la page.

Étape 2 : dans la page de l'appli

  1. Dans le panneau du bas, vérifie les deux dates (du 1er juillet 2025 à aujourd'hui) puis clique sur Démarrer.
  2. Le script entoure en rouge le champ date et le bouton d'extraction. Clique sur Oui, lancer. S'il s'est trompé, clique sur Non, je vais les montrer et suis les consignes.
  3. Laisse l'onglet de l'appli affiché à l'écran pendant le traitement (ne le réduis pas, ne change pas d'onglet) : un onglet caché est fortement ralenti par Edge. L'avancement s'affiche dans le panneau.
  4. À la fin, clique sur Télécharger le ZIP. Le fichier arrive dans ton dossier Téléchargements : il contient tous les Excel renommés et un rapport_extraction.csv.

Étape 3 : tout assembler en un seul fichier

  1. Une fois le ZIP téléchargé, double-clique sur 5_assembler.bat (il doit être dans le même dossier que assembler.py). Il prend tout seul le ZIP le plus récent de ton dossier Téléchargements.
  2. Le dossier assemblage s'ouvre. Il contient Mise_au_mille_complet_....xlsx : un seul tableau, une seule ligne de titres, toutes les lignes de tous les jours à la suite, et une première colonne Date programme pour les distinguer.
  3. Le sous-dossier fichiers_avec_date contient chaque fichier journalier avec cette même colonne ajoutée.

Si le ZIP n'est pas trouvé, fais-le simplement glisser sur 5_assembler.bat.

À savoir

  • Rien ne se télécharge pendant le traitement : les fichiers sont gardés en mémoire par Edge jusqu'au ZIP final.
  • Reprise : en cas de coupure ou de page rechargée, relance le script (favori ou console) puis Démarrer. Il reprend aux jours manquants, ce qui est déjà extrait est conservé.
  • Jours sans production : quand le tableau est vide, aucun fichier n'est créé. Ces jours figurent dans le rapport.
  • Sécurité : avant chaque extraction, le script contrôle que le sélecteur de date est bien sur le jour voulu. Si les premiers fichiers ont tous le même contenu, il s'arrête et le signale.
  • Tout effacer vide la mémoire (à faire une fois le ZIP récupéré et vérifié).
